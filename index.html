Suggested reading order

New here? They build on each other — foundations first, then the systems and protocols that tie them together.

  1. Building LLM Applications

    Start with the fundamentals — chains, RAG, stateful agents, and tracing. Everything else assumes this vocabulary.

  2. How Embedding Models Work

    Understand the vectors under the hood — what retrieval and semantic search are actually built on.

  3. TensorFlow

    The framework layer beneath the models — Google's platform, strongest on deployment reach.

  4. PyTorch

    The other giant — dynamic, pythonic, and dominant in research and the LLM ecosystem.

  5. Lab: Train a Licence Recognizer

    Put it into practice — a full from-scratch computer-vision lab: label, train weights, detect, OCR, serve.

  6. How YOLO & Label Studio Work

    Open up the two tools the lab uses — YOLO's detection architecture and Label Studio's labeling model.

  7. RAG vs CAG vs GraphRAG

    Go deep on grounding — how to get your data into the model reliably, and which retrieval method fits which corpus and question.

  8. Vector Databases Compared

    Where the vectors are stored and searched — from a one-line library to a distributed cluster.

  9. LangChain vs LlamaIndex

    Pick the framework to build on — orchestration-first (LangChain) or data/RAG-first (LlamaIndex), and when to combine them.

  10. Agent Development Kits

    Now zoom out: how the frameworks for building agents differ, and how to pick one for the job.

  11. Anthropic Agent Architectures

    The architectural vocabulary — workflows vs agents, the five patterns, and the agent loop.

  12. Google Agent Design Patterns

    The complementary taxonomy — predetermined vs dynamic routing, and the multi-agent topologies.

  13. Getting Started with Loops

    Put agents to work unattended — trigger, verify, stop — with the four loop types and their guardrails.

  14. REST vs GraphQL vs gRPC

    How services actually talk over the network — the API-design choices beneath every app and agent.

  15. APIs vs MCP

    How those agents reach the outside world — and why MCP standardizes connecting them to tools.

  16. Build MCP From Scratch

    Get hands-on — build an MCP server (app) and an MCP client (task), with examples and scenarios.

  17. WebMCP & A2A

    Where it's heading: tools in the browser, and agents that discover and delegate to each other.

  18. Web · API · AI Security

    Secure everything you've built — transport, identity, web/API risks, and the new AI/agent attack surface.

  19. OWASP — Top 10 & Toolbox

    The shared vocabulary of app security — the Top 10 risk lists and the standards/tools that operationalize them.

  20. Cyber Security

    Zoom out to the whole program — mechanisms, attack prevention, and how to govern & manage security.

  21. n8n — Workflow Automation

    Zoom out to the practical: wire apps and APIs into automated workflows — low-code, self-hosted, with code when you need it.

  22. Cloud Native

    The architectural approach beneath modern cloud apps — containers, microservices and orchestration, vendor-neutral.

  23. Concurrency Design

    Make it handle load safely — capacity, resilience, failure isolation, and per-run agent isolation.

  24. AWS Services Field Guide

    Learn the cloud building blocks — compute, storage, messaging, Bedrock — that agents and apps actually run on.

  25. IoT × Agents

    Put it all together in one end-to-end system: a device event triggers an agent that reasons and acts in the real world.
