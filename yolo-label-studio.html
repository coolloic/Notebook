How Ultralytics YOLO & Label Studio work

These two tools are the two halves of building a custom object detector: Label Studio is where you create the labeled examples, and Ultralytics YOLO is what learns from them and detects. This guide opens up how each one works internally, then shows the loop that connects them.

Label Studio— produces labels → Ultralytics YOLO— produces detections → your app
Where you've seen them. The licence-recognizer lab uses both end to end. This tutorial is the "how do they actually work?" companion.

Ultralytics YOLO  What YOLO is

YOLO — "You Only Look Once" — is a family of single-stage object detectors. Where older detectors scanned an image in two stages (propose regions, then classify each), YOLO predicts all the bounding boxes and their classes in one forward pass of a neural network. That's what makes it fast enough for real-time.

Ultralytics is the company/library that maintains the modern YOLO versions (YOLOv8, YOLO11, …) and wraps them in one friendly Python + CLI API — so you train, evaluate, predict and export without touching the network internals.

One look, many boxes. The model divides the image into a grid and, for every location and scale, predicts "is there an object here, where exactly, and what is it?" — then a cleanup step removes duplicates. No sliding windows, no region proposals.

Ultralytics YOLO  How YOLO works

Inside, a YOLO model is three parts plus a post-processing step:

🧱 Backbone

A convolutional network that turns pixels into feature maps — edges → shapes → objects, at several resolutions.

🔗 Neck

Fuses features across scales (FPN/PAN) so the model detects both tiny and large objects well.

🎯 Head

For each grid cell & scale, predicts a box (x,y,w,h), an objectness score, and class probabilities. Modern YOLO is anchor-free.

🧹 NMS

Non-Max Suppression: many cells fire for one object, so keep the highest-confidence box and drop others that overlap it (by IoU).

How it learns: the loss & training

During training the model compares its predictions to your labeled boxes and computes a loss with three parts: box loss (how far off the coordinates are), classification loss (right class?), and objectness/DFL loss (is something here?). Back-propagation nudges the weights to reduce that loss over many epochs. Starting from pretrained weights (transfer learning) means it already knows general vision, so it converges on your classes with little data.

Ultralytics YOLO  The Ultralytics library

One class, four verbs — the whole lifecycle:

the entire API surface
from ultralytics import YOLO

model = YOLO("yolo11n.pt")                 # load a pretrained model
model.train(data="data.yaml", epochs=100, imgsz=640)   # train on your data
model.val()                                # evaluate (precision, recall, mAP)
results = model("image.jpg")               # predict on new images
model.export(format="onnx")                # export for deployment

# read the predictions
for box, cls, conf in zip(results[0].boxes.xyxy,
                          results[0].boxes.cls,
                          results[0].boxes.conf):
    print(model.names[int(cls)], float(conf), box.tolist())

Your data is described by a data.yaml (train/val folders + class names), and labels are one .txt per image with normalized class x_center y_center w h lines. Ultralytics also auto-augments (mosaic, flips, HSV) during training — free robustness.

Label Studio  What Label Studio is

Label Studio is an open-source data-labeling platform. It gives you a browser UI to draw boxes (or polygons, keypoints, transcriptions, spans…) on your data and save them as structured annotations — the ground-truth examples a model like YOLO trains on. It handles images, text, audio, video and more, supports teams, and exports to the formats trainers expect (including YOLO).

Why a dedicated tool. Good labels are the highest-leverage part of a model. Label Studio gives you consistent classes, a fast keyboard-driven UI, review workflows, and clean exports — far better than home-grown scripts.

Label Studio  How it works

Four concepts:

📁 Project

A labeling job: its data, its label schema (config), and its annotations.

🧾 Labeling config

An XML-like template that defines the UI & the labels — what you can draw and tag.

🗂️ Tasks

Each data item (an image) is a "task" to be annotated.

✏️ Annotations

The saved answers — boxes with class labels — for each task.

The labeling config is the heart of it. For bounding-box detection you declare an image and the rectangle-labels:

labeling config — bounding boxes
<View>
  <Image name="img" value="$image"/>
  <RectangleLabels name="label" toName="img">
    <Label value="card_nz"      background="#22c55e"/>
    <Label value="f_dob"        background="#3b82f6"/>
    <Label value="f_licence_no" background="#a855f7"/>
  </RectangleLabels>
</View>

Then: import your images → annotate (draw a box, press the class hotkey, repeat) → export. Choose the YOLO export and you get the exact images/ + labels/*.txt + classes layout Ultralytics trains on.

Label Studio  ML backend & pre-labeling

Label Studio can connect to a model (an ML backend) that pre-annotates tasks. Instead of drawing every box from scratch, labelers correct the model's predictions — much faster. Connect your trained YOLO as the backend and each new image arrives already boxed, needing only fixes.

new image→ ML backend (YOLO) pre-labels→ human corrects→ annotation
Active learning. Route the model's least-confident predictions to humans first — you label the examples that teach the model the most, so accuracy climbs fastest per hour of labeling.

Together  The label ↔ train loop

The two tools form a flywheel that keeps improving your detector:

raw images→ Label Studio: annotate→ export YOLO→ Ultralytics: train→ weights .pt↺ back as ML backend
StepToolWhat happens
1. AnnotateLabel StudioDraw boxes + classes on your images
2. ExportLabel StudioEmit YOLO-format images/ + labels/ + data.yaml
3. TrainUltralyticsmodel.train(...) → best.pt weights
4. Pre-labelbothConnect best.pt as the ML backend to pre-annotate new data
5. Correct → retrainbothHumans fix the hard cases; re-export & re-train. Repeat.
The payoff. Early on you label everything by hand; once YOLO is decent, it does most of the drawing and you just correct — so each round is faster and raises accuracy. That's the whole game of building a custom detector.
