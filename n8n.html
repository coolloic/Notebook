n8n — automate the glue between your apps

n8n is a workflow-automation tool: you wire together triggers and actions on a visual canvas to connect apps, APIs and databases — automating the repetitive "when X happens, do Y and Z" work that would otherwise be manual or bespoke scripts. It's source-available and self-hostable, with an escape hatch to real code when the no-code nodes aren't enough.

a trigger fires→ nodes transform & route data→ actions happen
One line. n8n turns "I keep manually copying data between these five tools" into a workflow that runs itself — visually built, code-extensible, and running on your infrastructure if you want it.

Why  The problem it solves

Modern work is spread across dozens of SaaS apps that don't talk to each other. Bridging them means either manual busywork (copy a lead from a form into the CRM, ping Slack, add a row to a sheet…) or custom glue scripts you have to write, host, monitor and maintain forever. Both scale badly.

n8n collapses that into declarative workflows: connect a trigger to a chain of actions, and it handles the scheduling, the API auth, the retries and the data plumbing. It targets three pains at once:

🔁 Repetitive tasks

Anything you do the same way every time — notifications, data entry, syncing, reports — runs automatically.

🧩 App integration

400+ pre-built integrations (plus a generic HTTP node) so any two services can exchange data without custom clients.

🛠️ Glue-code sprawl

Replace scattered cron scripts and Lambda one-offs with one visible, maintainable, centrally-run place.

Mechanics  How n8n works

A workflow is a graph of nodes. A trigger node starts it (a schedule, an incoming webhook, or an app event), then data flows node-to-node as JSON items, each node transforming or routing them until action nodes do something in the outside world.

When a pre-built node doesn't exist, two escape hatches keep you unblocked: the HTTP Request node calls any REST API, and the Code node runs JavaScript (or Python) over the items — so a low-code workflow can drop into real code exactly where it needs to.

a Code node
// n8n "Code" node — runs over the items flowing through the workflow.
// Enrich each item, then hand them to the next node.
for (const item of $input.all()) {
  item.json.fullName    = `${item.json.first} ${item.json.last}`;
  item.json.processedAt = $now.toISO();     // n8n built-ins: $input, $now, $json…
}
return $input.all();

Character  What makes n8n distinct

🏠 Self-hostable

Run it on your own server (Docker/npm) so data never leaves your infrastructure — key for privacy, compliance and cost control.

🧑‍💻 Code when needed

Low-code by default, but the Code and HTTP nodes mean you're never boxed in like a pure no-code tool.

🤖 AI / agent nodes

Built-in LangChain-based nodes let you build LLM chains and tool-using agents inside a workflow.

💸 Predictable cost

Self-hosted is flat-cost rather than per-task — a big saver versus per-operation SaaS pricing at volume.

The trade-offs  Limitations

What to weigh before committing

License n8n is fair-code, not OSI open-source — distributed under the Sustainable Use License. Self-hosting for your own internal use is free, but offering n8n itself as a hosted service or embedding/white-labeling it commercially needs a licence. Read the terms if you plan to resell.

Ops Self-hosting has a cost of its own. Beyond a hobby instance you manage upgrades, a database (Postgres), and — to scale — "queue mode" with Redis and worker processes. That's real DevOps.

Scale Not a big-data engine. Items are processed largely in memory, so huge payloads or very high-throughput streaming can strain it. For heavy ETL or event streams, a dedicated pipeline (Airflow, Spark, Kafka) fits better.

Maintainability Large workflows get visually unwieldy; deep branching is hard to debug, testing is limited, and workflows are stored as JSON — versionable in git but not a first-class code-review/merge experience.

Integrations Some connectors are less deep or polished than a mature SaaS like Zapier's; you'll sometimes fall back to the raw HTTP node and wire auth yourself.

Net: n8n trades the turnkey polish (and cost) of hosted SaaS for flexibility, data control and code access. Great for technical teams; more setup than a point-and-click cloud tool.

If you…Reach for…

Want a powerful visual builder that's cheaper than ZapierMake
Need a fully OSI-open-source, self-hosted optionActivepieces or Node-RED
Automate hardware / IoT / event streamsNode-RED
Build data pipelines / DAGs in PythonApache Airflow

Rule of thumb. Non-technical + cloud → Zapier/Make. Technical team wanting control, flexibility and cost efficiency → n8n. Data engineering or reliability-critical orchestration → Airflow/Temporal (different tool for a different job).

Cheat sheet

QuestionShort answer
What is n8n?A source-available, self-hostable workflow-automation tool (node-based).
What problem does it solve?Automating repetitive multi-app tasks without bespoke, hard-to-maintain glue code.
How is a workflow built?A trigger node feeds action/logic nodes; data flows as JSON items.
Escape hatch from no-code?The HTTP Request node (any API) and the Code node (JS/Python).
Biggest caveats?Fair-code licence, self-hosting ops, and not built for big-data scale.
